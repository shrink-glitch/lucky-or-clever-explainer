# Lucky or clever? - Interactive explainer

An interactive guide to Gerstenberg, Ullman, Nagel, Kleiman-Weiner, Lagnado & Tenenbaum (2018), *Lucky or clever? From expectations to responsibility judgments*, Cognition 177, 122-141. https://doi.org/10.1016/j.cognition.2018.03.019

Live site: https://shrink-glitch.github.io/lucky-or-clever-explainer/

- Goalie/spinner and gardener tabs show the paper's own data (Appendix C, Tables C1 and C2: participants' mean ratings, agent inferences and model predictions).
- The "Run the model" tab implements the paper's model: softmax agents (beta = 1.5), Bayesian inference over agent types with the priors in Table A1, change in expected future reward, and pivotality, combined by a linear mapping that reproduces Table C2 predictions to within 1 point.
